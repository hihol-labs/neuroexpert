# SALES_LOG — журнал фазы C (ADR-002 / ADR-003)

Одна строка на рабочий день, ДО единственного активного implementation unit.
Формат (проверяется оракулом `scripts/verify-preflight.mjs`, режим
`--check-sales-today` — для pre-commit hook пункта C3):

```
YYYY-MM-DD | касания N | ответы N | демо N | оплаты N | необязательная заметка
```

Считается только последняя запись; строки без даты в начале — свободный текст.
Касания = исходящие контакты (письмо, звонок, визит, сообщение); ответы =
любая обратная реакция; демо = показ продукта; оплаты = деньги на счёте.

2026-09-02 | касания 0 | ответы 0 | демо 0 | оплаты 0 | бутстрап файла при закрытии AF-0 — цифры дня вносит владелец
