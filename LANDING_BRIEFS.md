## Стратегические правила (НЕ нарушать без перепланирования)

### Подписки и Knowledge API — независимые продукты

У нас **два разных продукта с разными ICP**:

| | Подписки экспертов (`/pricing`) | Knowledge API (`/for-agencies`) |
|---|---|---|
| Что продаём | публикация контента + гарантия цитирований | сырые данные о слепых зонах AI |
| ICP | психологи / юристы / нутрициологи (B2C) | SEO-агентства (B2B-разработчики) |
| Тарифы | Free / Starter / Pro / Expert / Business / Enterprise | Read free / Pro $99 / Enterprise |
| Чем платят за | свою публикацию + лиды | JSON-данные через API |

**Правило:** не объединять тарификации, не делать бандлы, не устраивать cross-sell **до первого платящего в каждом канале**. Любая попытка раньше = overengineering без данных, размывает ментальную модель пользователя, снижает конверсию.

**Что делать НЕЛЬЗЯ сейчас:**
- Включать API в Business-tier (24990 ₽) как «бесплатный» feature
- Показывать на `/pricing` блок «Knowledge API для агентств»
- Показывать на `/for-agencies` блок «А ещё подпишитесь как эксперт»
- Делать единый чекаут с обоими продуктами
- Любые reseller / partner программы между ICP

**Что МОЖНО рассмотреть позже** (после 1-го платящего в каждом канале) — см. BACKLOG.md → B-013.
