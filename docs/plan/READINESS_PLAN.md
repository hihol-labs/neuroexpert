## 1. Что уже автоматично (не трогаем, регрессии держим)

- **Business:** заказ → аккаунт по magic link → pre-flight → пара «вертикаль × город» →
  ЮKassa (webhook со сверкой суммы, идемпотентность) → письмо «оплата принята» → job аудита
  (degraded/failed, автовозврат при failed/SLA, SLA-sweep 5 мин) → письмо «отчёт готов» →
  `/orders/[id]` с авто-refresh. Метрика (8 целей), пример отчёта `/audit/example`.
- **Experts:** регистрация magic-link + профиль триггером; подписка через ЮKassa; cron сбора
  спроса и генерации заказов с TG-уведомлением; голос → STT (primary+fallback) → 5 форматов →
  валидация → `review`; `/api/publish` (владелец, FAQ-гейт, ISR, crosspost, TG); публичные
  страницы + Schema.org + sitemap; лиды с rate-limit и `/track`.
