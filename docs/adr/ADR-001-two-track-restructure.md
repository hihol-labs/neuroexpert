# ADR-001: Two-track restructure — параллельный маркетинг-трек и подъём монетизации в очереди

- **Status:** ACCEPTED (утверждено пользователем 2026-07-04, «Подтверждаю План В»)
- **Date:** 2026-07-04
- **Review date:** 2026-08-15

## Context

Цель плана — 2M ₽/мес MRR к декабрю 2026. На 2026-07-04: MRR = 0, платящих 0, пилотов 0, интервью 0, опубликованных профилей 0. Первая выручка в прежней последовательности этапов (1→17 строго сверху вниз) появлялась на Этапе 13 из 17 — при фактической скорости прохождения gates это Q4, декабрьская цель математически недостижима.

Проект 3+ недели заблокирован микроплатежами: Яндекс 360 (SMTP/magic link, ~1-2 тыс ₽/мес) блокирует Этапы 1/3/4/5/10; OpenAI billing (~$10-20) блокирует Этап 2 (754 failed jobs); статус заявки ЮKassa не проверялся с 2026-04-21; ahead-коммиты (11.1, 11.2) не задеплоены.

Маркетинг (Этап 9) стоял после 8 технических этапов — 0 рыночных касаний за всё время проекта, при том что контент-прогрев требует 4-6 недель инерции, а окно GEO/AEO first-mover сужается.

## Decision

Принят **Вариант B — Two-track**:

1. **Спринт 0 «Unblock Money»** (неделя 1) до любого нового кода: оплата Яндекс 360 → закрытие gate Этапа 1; пополнение OpenAI (или fallback expand_query на Claude) → разбор 754 failed jobs; проверка статуса ЮKassa; деплой ahead-коммитов.
2. **Tech-трек, новая очередность:** 1 → 2 → 3-lite (2 controlled E2E-прохода; остальные 3 — с реальными пилотами) → 5 (монетизация) → 4 → 13-lite (3-5 платных concierge-аудитов по ручным счетам) → 6/7/8 фоном → доводка 11/12 → 14 → 15. WIP=1 внутри трека сохраняется.
3. **Market-трек M0-M3** стартует немедленно и идёт параллельно (не содержит кода → не нарушает gate-дисциплину tech-трека). Детализация — в CURRENT_PLAN.md, секция «Маркетинговый трек M».
4. **Ревизия финцели:** 2M ₽ к декабрю → реалистичный коридор **700k-1.2M ₽ MRR** (NeuroExpert standalone); чекпоинты: сентябрь 100-150k, октябрь 300k, ноябрь 500-700k. Сентябрь <50k → триггер пересмотра стратегии. 2M остаётся stretch-целью портфеля.
5. **Квота времени фаундера:** ~60% tech / ~40% market, ревизия раз в 2 недели.
6. **Жёсткое правило CTA:** до закрытия gate Этапа 1 ни один маркетинговый CTA не ведёт на регистрацию — только подписка на TG-канал и форма заявки на пилот.

## Alternatives considered

- **A — Stay the course (строго 1→17):** отклонён — первые деньги в Q4, цель провалена, 6 месяцев без рыночных сигналов, риск строить не то.
- **C — Service-first pivot (аудиты руками, продукт потом):** отклонён — противоречит решению SaaS-first от 2026-05-10, воспроизводит агентство, не масштабируется.

## Consequences

- (+) Выручка возможна с августа (платные concierge-аудиты уже разрешены Этапом 5 п.10 и решением SaaS-first 2026-05-10); рыночные сигналы — с июля.
- (−) Нагрузка на соло-фаундера; лёгкое ослабление gate Этапа 3 (3-lite).
- Митигации: правило CTA (п.6), квота времени (п.5), чекпоинт review 2026-08-15: **≥5 оплаченных аудитов и ≥300 подписчиков TG-канала**, иначе откат/пересмотр решения.
